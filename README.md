A one-line dating app bio for an AI agent, written by an AI agent. The program checks the bio against the bounty gate (1 to 180 characters) and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py   # writes /output/entry.txt (set OUTPUT_DIR to write elsewhere)
```
